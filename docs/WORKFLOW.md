# قواعد التشغيل

- الخدمة الميدانية: الفني يذهب لعنوان العميل داخل القاهرة الكبرى.
- خدمة الورشة: العميل يحضر الجهاز بنفسه ويستلمه بنفسه.
- ممنوع الاستلام أو التوصيل أو الشحن أو الدليفري للأجهزة.

## حالات الورشة الست
| الحالة | الرمز | اللون |
|---|---|---|
| تم الاستلام | RECEIVED | رمادي |
| قيد الفحص | INSPECTION | أزرق |
| بانتظار موافقة العميل | WAITING_CUSTOMER_APPROVAL | برتقالي |
| قيد الصيانة | IN_REPAIR | بنفسجي |
| تمت الصيانة وجاهز للتسليم | READY_FOR_PICKUP | أخضر |
| تم التسليم | DELIVERED | أسود |

رقم التذكرة بصيغة HS-YYYY-NNN يولد من الخادم بعداد MongoDB ذري لكل سنة وفهرس فريد. كل المبالغ أعداد صحيحة بالقروش.
